## Deviations

1. **Not a fresh stack.** Volumes from earlier runs were kept; the stack holds integration-test residue, which `AisreWorkflowStalled` counts.
2. **Severity confirmed early in each run** (`sev3` by the incident lead, before the approval request), so one approver was needed and ST-07's refusal could show; with severity unconfirmed the change is high-impact and needs two.
3. **The ineffective fix is planted** with a runtime override on the fake release process. It is an honest stand-in for a cause outside the repository, not a patch that fails on its own.
4. **Minute resolution.** The fake monitoring source gives a minute the configuration last set within it, so run 1's watch attributed the whole 06:59 minute to the 06:59:58 regression.
5. **Hand-triggered jobs.** Both reconciliation schedules were triggered by hand, not waited for.
6. **A shortened watch** (240 s) for the demo; the default is 3600 s.
7. **Who ran it.** A coding agent; Artifact 13.12 does not count that as any role owner's confirmation.
