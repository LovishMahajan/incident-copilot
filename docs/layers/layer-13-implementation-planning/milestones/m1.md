## Deviations

1. **The fake provider throughout.** Every model answer is scripted (above). The demo's diagnosis is the right one because its script says so.
2. **Evidence events carry the replay clock.** With `replay_as_of` set, `aisre.evidence.collected.v1` events are timed at the replay's as-of time (2026-10-20T14:20:00Z), so the timeline's times step back between sequence 2 and 19 while the sequence stays in order.
3. **Temporal shown through the CLI**, not by eye in the UI, as at M0.
4. **Docker's layer cache.** `docker compose up --build` in the clone reused image layers built on this machine from the same files.
5. **The honesty run withholds files, not a source's availability.** The fake monitoring source answers 404 for the withheld change history, which the adapter records as a gap, as ADR-54 needs; a real source failing differently (a timeout, a 5xx) is covered by the collector's unit tests, not this run.
6. **Who ran it.** A coding agent; Artifact 13.12 does not count that as any role owner's confirmation.
